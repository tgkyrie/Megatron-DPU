# Result Provenance

This file maps the current `docs/benchmark_runs/` result directory families to
tracked scripts under `tools/`. Benchmark output directories remain ignored; the
scripts and this provenance map are the reproducible artifacts to keep in git.

Audit date: 2026-06-29.

| Result directory pattern | Count observed | Script / status | Keep decision |
| --- | ---: | --- | --- |
| `*-megatron-host-vs-dpu-dataaddr/` | 95 | `tools/run_megatron_ucx_semantic.py` | Keep. This is the current NCCL / Host-PS / DPU-PS Megatron runner and covers the latest DP Qwen-3B, TP Llama2-7B, and DPTP Qwen3-4B checks. |
| `*-paper-revision-megatron/` | 18 | `tools/run_paper_revision_megatron.sh` | Keep. This is the main paper Megatron matrix runner for DP / TP / TP+DP, NCCL vs Host-PS, server count, partition, overlap, and long loss runs. |

| `*-fresh-fused-image-sync/` | 1 | Image/container synchronization inventory | Not a benchmark runner output. Keep as operational evidence only. |

Conclusion:

- Every tracked `tools/` runner maps to at least one benchmark result family or
  to the current Megatron operational runbook.
- Some old result directories are intentionally documented as historical or
  bring-up evidence rather than being forced onto a current script.
- Do not delete a runner only because a newer runner supersedes it; the older
  script may still be the exact provenance for an old result table.
